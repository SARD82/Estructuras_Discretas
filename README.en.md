Activities for the **Discrete Structures** course at the Faculty of Engineering, UNAM.

## 📘 What You'll Find Here:

- 📐 **Assignments and exercises** on mathematical logic, set theory, and graph theory.
- 🐍 **Python implementations** of graph algorithms.
- 📄 **LaTeX documents** (formal homework and reports).
- 📁 **Final Project** for the course.
- 📝 **Summaries** of the first course topics.

## 🛠️ Technologies & Applied Concepts

- **Python 3** — Maze-solving agents, graph algorithms.
- **LaTeX** — Formal mathematical typesetting for assignments and reports.
- **Graph theory:** BFS/DFS traversals, directed graphs.
- **Propositional logic** and set theory.
- **Markov chains** and discrete probability.

## 📂 Repository Structure

```
├── LaTeX/                              # Homework and reports in LaTeX format.
│   ├── Aprendiendo/                    # Practice and exploration exercises.
│   └── Resumen_Primeros_3_Temas/       # Summaries of logic, sets, and relations.
├── Proyecto_Final/                     # Course final project.
│   ├── agente_laberinto.py             # Agent that solves a maze using graphs.
│   └── agente_laberinto_aleatorio.py   # Variant with a randomly generated maze.
├── requirements.txt                    # Python environment dependencies.
```
